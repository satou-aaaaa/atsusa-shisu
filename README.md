# 暑さ指数よみ

その過ごし方、よい？よくない？ 暑い日の場面や熱中症の手当てが、暑さ指数（WBGT）の指針で「よい」か「よくない」かを当てながら、熱中症を防ぐ目安が身につくゲームです。

- 遊ぶ: <https://satou-aaaaa.github.io/atsusa-shisu/>
- 1問ずつ、場面が「○ よい」か「✕ よくない」かを選ぶか、3つの場面から「よくないのはどれ？」「よいのはどれ？」を選びます。答えると、なぜそうなのかと、暑さ指数の段階（危険・厳重警戒など）・出典が出ます。
- 今日の5問（○✕・○✕・どれ・○✕・どれ）と上級（「どれ？」×3・ヒントなし）はだれでも同じで1日1回。とことん（何問続けて当てられる？）と練習（なかまを選ぶ）は何度でも。
- 出会った場面は「めやす帳」に集まり、いつでも答え・なぜ・段階を読めます。実績・カレンダー（7日前まであとから遊べる）もあります。時間制限はありません。
- 場面は45。なかまは「ふだんのくらし」「運動・部活」「指数とアラート」「熱中症になったら」の4つ。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（場面や答えは入りません）。

## 目安の出どころ

- 暑さ指数の段階と目安は、環境省「熱中症予防情報サイト」の [暑さ指数（WBGT）について](https://www.wbgt.env.go.jp/wbgt.php) から書き写しました（2026-11-07 に確かめた）。日常生活の指針は日本生気象学会「日常生活における熱中症予防指針 Ver.4」を環境省が改編したもの、運動の指針は日本スポーツ協会「熱中症予防運動指針」です。
- 熱中症警戒アラート（日最高の暑さ指数が33に達すると予測）・特別警戒アラート（35）は、環境省の [警戒アラート](https://www.wbgt.env.go.jp/about_alert.php)・[特別警戒アラート](https://www.wbgt.env.go.jp/about_special_alert.php) の発表基準です。
- 手当ては、環境省 [熱中症環境保健マニュアル2022](https://www.wbgt.env.go.jp/heatillness_manual.php) から書き写しました。
- このゲームは目安を覚えるためのもので、体調の判断や診断の代わりにはなりません。具合が悪いときは医療機関に相談し、呼びかけに応えないときはすぐ119番へ。まちがいを見つけたら、[感想のフォーム](https://github.com/satou-aaaaa/atsusa-shisu/issues/new?template=feedback.yml)で教えてください。
